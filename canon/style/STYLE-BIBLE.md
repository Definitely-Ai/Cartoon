# Style Bible

Purpose: the visual law of the strip — every drawing decision that must be identical from cartoon number one to cartoon number one thousand lives here. Source: the founder's series bible for "The Swinging Door."

## Line & Ink

The cartoon is a single-frame **black-and-white ink wash** editorial cartoon with a dry American magazine cartoon feel. Confident editorial linework over wash tones; grayscale exists only as ink wash, never as color.

Working defaults (approve or veto in the style session):

- **Three values only**: paper white, one mid-gray wash, solid black ink. A second, darker wash is allowed in shadows sparingly; never a smooth digital gradient.
- **Brush-pen line**, variable weight — thick where forms sit (the bar, shoulders), thin for features and detail. Loose but certain; no sketchy multiple strokes, no cross-hatching.
- **Faces do little and mean much**: dot eyes, single brow strokes, small mouths. The gag is in posture and placement, not grimaces.

## Black & White Rules

Strictly black and white. Ink wash (grayscale tone) is the shading method — this resolves the earlier pure-B&W-vs-halftone question in favor of **wash**. No color anywhere, ever, including signage, drinks, and the American flag lapel pin (rendered in ink, not color).

## Panel Format

Single frame. Most cartoons are set inside The Swinging Door bar (see `/canon/settings/SETTINGS-BIBLE.md`).

Working defaults: portrait 4:5 preferred, square allowed; a single hand-ruled border line (slightly imperfect, never a perfect vector stroke); the drawing breathes — generous margin inside the border, one focal action, no edge-to-edge clutter.
The deterministic dialogue field is appended below either supported illustration shape, so the finished PNG is taller than the drawn panel.

## Caption Convention

Every cartoon has dialogue (see the Comedy Bible's caption rules). Working convention: the exact dialogue is typeset into a warm-white field below the illustrated panel, magazine-style, and is part of the finished PNG. It must match the `caption` in the cartoon's JSON exactly. Each published cartoon also carries a **catalog and dating line displayed below the cartoon but not part of the cartoon** — in this repo that line is generated by the site from `meta.json` (date + edition number), so the PNG never contains the title, date, edition, proof label, or catalog line.

## Signature / Watermark

Working default: a small hand-drawn monogram, lower right, inside the border — quiet enough to miss on first read. Final mark pending the founder's own hand.

## The bar window rule

When the scene is inside the bar, the bar's name should appear in the window **reversed** — lettered as it would read from outside. This is a continuity detail prompts must preserve.
